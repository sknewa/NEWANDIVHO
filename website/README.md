Welcome to the official static website for **NEWANDIVHO (PTY) LTD** ("*Life With Technology*").

## 🌐 Free Deployment Options

- **GitHub Pages:** Create a GitHub repository, upload the `website/` contents, and enable GitHub Pages under Settings > Pages.
- **Netlify:** Drag and drop the `website/` folder directly onto [Netlify Drop](https://app.netlify.com/drop).
- **Vercel:** Run `vercel` inside the `website` directory or connect your GitHub repository.
- **Traditional Web Host / cPanel:** Upload the contents of `website/` to your `public_html` directory via FTP or File Manager.
